# Friday Night Boiled: ReMemed

![Animated-Banner](https://github.com/user-attachments/assets/5830221d-d954-4be3-afe8-caae364a5881)

**Friday Night Boiled: ReMemed** is a mod built using the **[Codename Engine](https://github.com/CodenameCrew/CodenameEngine)**.

Codename Engine is a cross platform [Friday Night Funkin'](https://github.com/FunkinCrew/Funkin) Engine aimed at simplifying modding focusing on softcoding, along with extensiblity and ease of use.

> [!NOTE]
> This project is a modification of Friday Night Funkin' built on the Codename Engine platform.

---

## About the Mod

Friday Night Boiled: ReMemed is a mod that brings various memes into Friday Night Funkin' with a unique art style and custom gameplay mechanics powered by Codename Engine.

*For instructions on how to build the mod from source, please refer to the [Building Guide](building/README.md).*
